# Projeto ONG - Teste Unimar

Este projeto possui um frontend com Vite e um backend com Express API.

## Como rodar o projeto:

1. Abra o terminal na pasta do projeto e instale as dependências:
npm install

2. Inicie a API (Backend) em um terminal:
npm run api

3. Abra um SEGUNDO terminal e inicie o Frontend (Vite):
npm run dev


## Caso ainda der erro:

1. Abra o terminal e cole o seguinte comando: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

2. Se não der nenhum erro, feche o terminal, feche o VS caso esteja usando e volte a tentar com os comandos para rodar iniciando pelo número 2

3. Caso peça perimissões pode aceitar todas, essa é uma limitação do windows em utilziar direto!
